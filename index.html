Dudas Habituales

Preguntas frecuentes

Todo lo que necesitas saber antes de iniciar tu proyecto.

¿Cuál es la diferencia entre los tres planes? +

La Landing Esencial está pensada para negocios que necesitan una presencia sencilla y contacto por WhatsApp. La Web Profesional ofrece una solución personalizada y más completa. La Web App incorpora funcionalidades, usuarios, paneles privados y base de datos.

¿Qué incluye el plan Web Profesional de $150.000 + IVA? +

Incluye diseño y desarrollo personalizado, hosting, dominio por 1 año, certificado SSL, optimización para celulares, WhatsApp, Google Calendar y 3 meses de gestión gratuita.

¿Cuánto tiempo duran el hosting y dominio del plan profesional? +

Tanto el hosting como el dominio incluidos en el plan profesional duran 1 año completo desde la publicación del sitio.

¿Qué ocurre después de los 3 meses de gestión gratuita? +

El sitio continúa funcionando normalmente. Si necesitas modificaciones posteriores, cada solicitud puntual tiene un valor de $20.000 + IVA.

¿El precio de una Web App siempre es $499.990 + IVA? +

No. Ese es el precio inicial para una aplicación de alcance acotado. El valor final depende de las funcionalidades, integraciones, cantidad de módulos y complejidad del proyecto.

¿La infraestructura de una Web App está incluida? +

El valor de desarrollo no incluye de forma indefinida los servicios externos. Base de datos, servidores, almacenamiento, dominio y otros servicios se cotizan según el uso y necesidades de cada aplicación.

¿Cómo funciona la oferta de 10 correos profesionales? +

El servicio incluye 10 cuentas de correo profesional asociadas al dominio de tu empresa. Los primeros 2 meses son gratis y desde el tercer mes el valor es de $7.990 CLP mensuales.
